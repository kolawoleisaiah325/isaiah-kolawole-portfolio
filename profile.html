Featured project

Health Programme Analytics — a reproducible Python pipeline for a synthetic facility network, combining reporting validation, a Streamlit dashboard, forecasting comparisons, and evidence-checked AI draft briefs.

  • Distinguishes accepted counts, missing reports, and invalid submissions across 216 facility-months, retaining an audit trail.
  • Compares three forecasting methods using a time-based holdout. Holt-Winters recorded MAE 27.38 doses and WAPE 3.61% across nine complete synthetic months.
  • Supports a PostgreSQL schema and tested SQL views, alongside CSV outputs used by the dashboard.
  • Uses local Ollama generation with citation and numeric checks, a deterministic fallback, and human review.

Synthetic demonstration, not real-world programme impact. The same holdout selected and evaluated the model; independent validation remains necessary.

GitHub Code Chat

Local AI codebase assistant — a Python and Streamlit application with a bundled offline example, BM25 keyword retrieval, local embeddings, hybrid rank fusion, and Ollama-generated explanations.

  • Reads public repositories at a pinned commit and preserves file/line references.
  • Exposes the source excerpts behind answers, with citation-number checks and graceful model-failure handling.
  • Includes 20 authored evaluation questions, recorded method comparisons, documented model errors, and automated tests.

Local engineering prototype. Its five-file example evaluation does not establish performance on real repositories or answer accuracy.
